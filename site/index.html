READ THE BOUNDARY

Scope and limits

A / LANGUAGE

A documented subset

Static analysis supports a narrow, direct-registration subset of JavaScript and TypeScript. Imported helpers, dynamic registrations, branches, and broader interprocedural flows can fall outside it.

B / DISCOVERY

Reviewed fixture only

Optional live discovery is limited to one reviewed fixture on verified macOS isolation. Arbitrary targets and unsupported platforms are blocked. Default validation stays offline.

C / INTERPRETATION

No security score

Findings preserve evidence, assumptions and limitations. MCP Guard is not a runtime firewall, exploit confirmation, or security certification.

EVALUATION / OFFICIAL REFERENCE EXAMPLES

Coverage on a pinned external sample

Across seven unchanged official SDK example files, the analyzer reported four recognized registrations in aggregate. Manual source review identified 20 factory-bound registrations outside the supported shape. Every file had incomplete coverage. Zero findings and zero parse failures do not support an accuracy estimate or a security verdict.
